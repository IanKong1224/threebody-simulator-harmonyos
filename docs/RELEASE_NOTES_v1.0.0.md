# v1.0.0 · 首次源码发布

署名：@差评硬件部。个人发布：IanKong1224。许可证：Apache-2.0。

一份源码提供三体模拟器、Pro、Pro Max 三种构建，包含实时物理积分、预设和自定义初值、线条/粒子轨迹、恒星表面与 HDR 光晕、可选 XEngine 空间超分及 Graphics 帧生成接入。

## 包含

- 独立生成的 DevEco 工程与签名配置，默认构建无签名 HAP。
- 轨迹 JSON/CSV、约半秒的帧率 CSV；区分真实渲染、合成提交和可用时的实际呈现数据。
- 物理模型、构建签名、帧率说明和“焚决”开发提示词。
- 主机测试、着色器校验、发布清单检查和 CI。

## 验证与限制

macOS 主机 17 项 C++ 测试、7 项 Python 回归通过；三个版本从干净源码目录构建成功，Pro Max 的厂商 SDK ON/OFF 均验证编译。真机运行和厂商加速收益仍需在具体设备上验证，120 Hz 是请求目标。

GitHub Actions 的 Linux/macOS 主机测试、源码检查和着色器校验均通过。计时测试检查调度策略与计数正确性，不把云端测试机的实际 FPS 作为产品性能指标。Windows 尚未验证。

发布附件只包含源码及校验和，不含证书、厂商 SDK、设备记录或通用签名安装包。下载安装源码后，按 README 在自己的环境中构建与签名。

这是一份真实的当前源码快照，不复刻历史提交。物理模型允许碰撞与逃逸；预设验证时长是有限的。表面与光晕是简化视觉效果，不是恒星内部流体或实时光线追踪。
