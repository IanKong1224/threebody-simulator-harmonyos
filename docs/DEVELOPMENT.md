# 给观众的开发路线

可以直接构建三个版本，也可以把 `prompts/焚决.md` 交给开发助手逐步实现。提示词是目标和验收要求，实际接口仍需查阅目标 SDK。

1. **先算对**：实现双精度牛顿引力和 RK4，核对单位、八字短窗口、能量/动量；输出可重算的轨迹。
2. **先看见**：基础版以点与线展示位置和历史，增加相机与控制面板。避免把显示半径混作物理半径。
3. **增加视觉工作量**：Pro 使用球体、细圆粒子、轨迹渐细渐淡。粒子是渲染数据，不是独立引力天体。
4. **提高细节与误差控制**：Pro Max 增加程序化恒星表面、HDR/Bloom、亮度滑块和 RK45，分开验证物理与视觉变化。
5. **定位并行等待**：先确认 Release，再分析物理、几何准备、GPU 和提交等待。CPU 总占用低不表示单线程没有卡住。
6. **再接系统能力**：可选超分和超帧，先检测 SDK/设备支持；保留开关和可理解的失败回退。
7. **诚实记录输出**：区分真实渲染、合成提交、实际呈现与屏幕刷新率，导出半秒样本和轨迹供检查。

工程是当前状态快照。三个构建版本不是每次历史提交的精确重放；教程描述的是可复现的实现顺序，不伪造过去每个阶段的代码、性能数据或设备测量。

提出问题时附上最小复现步骤、构建参数、相关日志、设备系统版本和是否开启加速。删除账号、设备标识与签名信息后再上传。
