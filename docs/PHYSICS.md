# 物理模型与验证边界

## 模型

三颗近太阳质量主序星，质量可编辑范围为 0.8～1.2 倍太阳质量。恒星之间使用牛顿点质量引力；物理半径用近太阳范围的经验近似 `R/R☉ = (M/M☉)^0.8`，只用于接触检测。屏幕中的球体和光晕为便于观察进行了艺术化显示，不与碰撞半径等比例。

内部采用 G=1、太阳质量单位与 AU 长度单位。时间单位为 `sqrt(AU³ / GM☉)`，约 58.13 地球日；速度单位约 29.78 km/s。界面换算为地球日/年和 km/s。常数集中在 `core/simulation/StellarUnits.h`。

基础版和 Pro 使用 RK4；最大内部时间步 0.0001（约 8.37 地球分钟），近距离根据距离、速度和动力学时间进一步缩小。Pro Max 使用 Dormand–Prince 5(4)，最大内部时间步 0.001，局部误差控制 rtol=1e-10、atol=1e-12，拒绝不合格试步。容差不是整个模拟的全局轨迹误差保证。

不模拟恒星内部流体、核反应、潮汐、相对论效应或碰撞合并。检测到接触或计算超限时回滚当前检查点并暂停，不通过修改引力或强迫返回让轨迹保持好看。检测不是连续碰撞求根，不能宣称精确定位了首次接触时刻。

## 预设

| 预设 | 初始状态方式 | 已有回归测试的有限区间 |
|---|---|---|
| 八字 | 等质量平面八字的常用有限精度初值 | 用作短窗口和算法验证；并非混沌立体示例 |
| 旧不对称初值（仅保留在核心与测试） | 手工构造的不对称状态、移到质心系 | 不承诺长期束缚，当前菜单以随机立体取代 |
| 随机立体 | 等质量、固定八字速度，只随机位置；拒绝过近起点 | 不承诺不碰撞、不逃逸；保存完整起点比只保存种子更可靠 |
| 长时立体 | 经筛选的空间初值 | t=400，约 63.66 地球年 |
| 稳定立体 | 内双星、外伴星，轨道面有倾角 | t=630，约 100.27 地球年 |
| 三日交错 | 筛选出反复接近、远去、返回的有限窗口 | t=80，约 12.73 地球年 |

所有预设运行时重新积分，没有轨迹回放。测试中的长期预设主要用 RK4 和更小步长交叉检查；它们不构成所有算法、所有修改参数、无限时长的稳定性证明。初值见 `core/physics/InitialConditions.cpp`，标准见 `tests/*triple_test.cpp`。

《三体》没有提供可直接用于复现的完整恒星初值，本项目也不是小说官方模型。现实存在三星系统，不能宣称宇宙中不存在真正的三星系统。

## 怎样判断误差

1. 导出同一初始状态、模拟时刻、单位和积分设置下的位置与速度。
2. 用更小时间步/更严容差复算相同有限区间，再比较位置、速度和守恒量。
3. `reference/generate.py` 用 Python Decimal 产生独立短窗口 RK4 参考；更高精度仍不是解析真解。
4. 混沌轨迹可能随时间分离，不能把“出现逃逸”直接当作数值错误，也不能把能量守恒良好当作每个位置都准确的证明。

对应科学背景：八字轨道可参考 [Chenciner 与 Montgomery 的论文](https://arxiv.org/abs/math/0011268)。本文没有宣称其他筛选初值来自该论文，也没有复制论文文字或图像。
